## Quick install

From the Claude plugin directory:

- **claude.ai (Cowork and the Claude apps):** Customize, then Plugins, then search for "Writing With Agents", or open the [directory listing](https://claude.ai/customize/plugins/id/f54e0a10-f5d3-48c4-addb-2c74360c8130%40anthropic-plugin-directory) while signed in.
- **Claude Code:** run `/plugin`, open Discover, and search for "Writing With Agents" (Anthropic Directory).

Or, inside Claude Code, add this repo as a plugin marketplace and install:

```
/plugin marketplace add Jeffallan/writing-with-agents
/plugin install writing-with-agents@writing-with-agents
```

Or via [skills.sh](https://skills.sh):

```bash
npx skills add Jeffallan/writing-with-agents
```

See the [README](/writing-with-agents/readme/) for full usage and architecture details.
